Weakness
V1 consistently underperforms both equal-weight buy-and-hold and plain momentum on Sharpe and CAGR, and its results are nearly indistinguishable from the volume-momentum benchmark despite much higher turnover.

Evidence
Best v1 config (top_n=2, mom_window=126): validation Sharpe 0.542, CAGR 0.100, max DD -0.295, dev turnover 11.66. Equal-weight buy-and-hold: Sharpe 0.8699, CAGR 0.177, max DD -0.3373, turnover 0. Plain momentum: Sharpe 0.9269, CAGR 0.205, max DD -0.2901, turnover 5.99. V1's turnover is nearly double plain momentum's for a materially worse risk-adjusted return.

Change
Add a volatility filter to the selection step: only consider a ticker for the top-N ranking if its trailing realized volatility (e.g. 63- or 126-day annualized) is below a threshold at each rebalance, on top of the existing momentum ranking.

Expected
Should reduce turnover and tail risk by excluding erratic names from the eligible set before ranking, potentially improving risk-adjusted return without changing the core momentum signal.

Overfit risk
A volatility threshold is an extra free parameter tuned against the same development window every other choice in this study has been tuned against; it should be swept across a reasonable range (not just one value) and checked for validation-period stability, not selected because one threshold happens to look best on development data alone.
